API de Esportes

Placar, agenda, classificação, times, escalações e estatísticas de jogos reais. Gratuita, sem chave e com CORS liberado.

Como usar

Base: /api/v1. Todas as respostas são JSON no formato { generatedAt, source, data }.

const res = await fetch('https://ankidroisconta-sudo.github.io/api/v1/brasileirao/today.json');
const { data } = await res.json();
data.forEach(j => console.log(j.home.team.name, j.home.score, 'x', j.away.score, j.away.team.name));

Endpoints

CaminhoConteúdo
status.jsonHorário da última atualização, totais e avisos
leagues.jsonLigas disponíveis e seus endpoints
live.jsonTodos os jogos ao vivo agora, de todas as ligas
today.jsonTodos os jogos de hoje (horário de Brasília)
{liga}/games.jsonJogos dos últimos 3 dias e dos próximos 7
{liga}/today.jsonJogos de hoje da liga
{liga}/live.jsonJogos ao vivo da liga
{liga}/standings.jsonClassificação (pontos, vitórias, saldo, zona)
{liga}/teams.jsonTimes, escudos e cores
games/{id}.jsonDetalhe do jogo: escalações, estatísticas, lances, árbitros, confronto direto. Disponível quando o jogo tem detailUrl.

Avisos

Os dados vêm dos endpoints públicos (não oficiais) da ESPN e são atualizados a cada ~10 minutos, então o placar ao vivo pode atrasar. A ESPN pode mudar ou bloquear esses endpoints sem aviso. Use em projetos pessoais; para uso comercial, contrate um provedor licenciado.
